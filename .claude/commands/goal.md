เข้าโหมดทำงานต่อเนื่อง:
- ทำงานจนบรรลุเงื่อนไขความสำเร็จข้างบนให้ครบ ห้ามหยุดกลางทางเพื่อถามว่า "ให้ทำต่อไหม" หรือรายงานความคืบหน้าแล้วรอ
- ถ้าเจอ error ให้พยายามแก้เองก่อน (อ่านไฟล์เพิ่ม, ลองวิธีอื่น) — หยุดถามเฉพาะเมื่อ block ด้วยข้อมูลที่มีแต่ผู้ใช้เท่านั้นที่ตอบได้
- ก่อนจบ ตรวจสอบตัวเองว่าเงื่อนไขความสำเร็จทุกข้อถูกทำครบจริง (ไฟล์ done/review ที่ระบุถูกเขียนแล้ว, pytest/validation ผ่านแล้ว)
- **ข้อยกเว้นด้าน safety (สำคัญกว่าโหมด goal):**
  - รัน `references/ac-modbus-ab64-test.py` แบบ**อ่านอย่างเดียว** (`--once` หรือ poll) กับ hardware จริง = ทำ solo ได้
  - **เขียน**ค่าไปยัง register จริง (on/off, mode, setpoint ผ่าน `write_register` หรือทดสอบ climate entity จริงกับแอร์ในห้อง server) = **ต้องหยุดขอ confirm จากผู้ใช้ก่อนเสมอ** — goal mode ไม่ override กฎนี้
  - commit/push/merge ไป public repo = ต้องขอ confirm จากผู้ใช้ก่อนเสมอ
- เสร็จแล้วสรุปสั้น ๆ ว่าทำอะไรไป และส่งสัญญาณกลับตาม workflow ใน role file ของคุณ
